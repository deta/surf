# Hypocalcemia in Pediatric Patients - PowerPoint Presentation

## Overview
This project generates a professional PowerPoint presentation on **Hypocalcemia in Pediatric Patients** with modern design, 3D-style illustrations, and comprehensive medical content.

## Features
- ✅ **12 Professional Slides** covering all aspects of pediatric hypocalcemia
- 🎨 **Modern Medical Design** with blue and teal color scheme
- 📊 **Visual Elements** including flowcharts, diagrams, and categorized information
- 🏥 **Medically Accurate Content** based on AAP guidelines and current literature
- 📋 **Case Study** with real-world application
- 🎯 **Clear Structure** suitable for medical education

## Slide Contents

1. **Title Slide** - Professional introduction with calcium ion visual
2. **Agenda** - Clear outline of presentation topics
3. **Introduction** - Definition, importance, and epidemiology
4. **Pathophysiology** - Calcium homeostasis flowchart and mechanisms
5. **Causes** - Categorized by nutritional, endocrine, renal, iatrogenic, and neonatal
6. **Clinical Presentation** - Symptoms by system (neuromuscular, cardiovascular, skeletal, infant-specific)
7. **Diagnosis** - Laboratory tests, imaging, and diagnostic approach
8. **Management** - Acute and chronic treatment protocols
9. **Complications & Prevention** - Short/long-term complications and prevention strategies
10. **Case Study** - 6-month-old infant with vitamin D deficiency
11. **Key Takeaways** - 5 essential points for clinical practice
12. **Conclusion & Q&A** - Thank you slide with references

## Installation

```bash
npm install
```

## Usage

Generate the presentation:

```bash
npm start
```

Or:

```bash
npm run generate
```

This will create a file named `Hypocalcemia_Pediatric_Patients.pptx` in the current directory.

- **Primary Blue**: #0066CC (Medical professionalism)

## Customization

You can customize the presentation by editing `generate-presentation.js`:
- Change colors in the `colors` object
- Modify content in each slide section
- Adjust layout dimensions
- Add or remove slides
- Update medical content

## Requirements

## Notes for Presenters

- Full presentation: 25-30 minutes
- With Q&A: 35-40 minutes

### Target Audience
- Pediatricians
- Medical students
- Pediatric nurses
- Healthcare professionals

### Presentation Tips
1. Review speaker notes before presenting
2. Emphasize the case study for practical application
3. Allow time for questions after complex slides
4. Use the key takeaways slide for summary
5. Provide handouts of key slides if needed
